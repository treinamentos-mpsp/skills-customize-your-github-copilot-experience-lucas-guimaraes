
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir o clássico jogo de adivinhar palavras usando strings, loops, condicionais, seleção aleatória e entrada de dados do usuário em Python.

## 📝 Tarefas

### 🛠️	Seleção Aleatória de Palavras

#### Descrição
Crie uma lista predefinida de palavras e sorteie uma delas no início de cada partida.

#### Requisitos
O programa concluído deve:

- Conter uma lista predefinida de palavras.
- Escolher uma palavra aleatoriamente a cada partida usando `random.choice()`.

### 🛠️	Palpites e Progresso

#### Descrição
Permita que o jogador adivinhe letras e veja o progresso da palavra oculta.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras usando `input()`.
- Mostrar o progresso atual no formato `_ _ _`, revelando as letras já acertadas.

### 🛠️	Tentativas e Fim de Jogo

#### Descrição
Controle as tentativas incorretas e encerre a partida ao final do jogo.

#### Requisitos
O programa concluído deve:

- Rastrear o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir mensagens de vitória ou derrota.
